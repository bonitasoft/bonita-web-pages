# Bootstrap default theme

Application theme based on bootstrap "Default" theme. (see http\://bootswatch.com/default/)

- **Family:** Theme (SCSS / node-sass) — `community/other-pages/bootstrap-default-theme`
- **contentType:** theme · **id:** `custompage_bootstrapdefaulttheme`
- Styles compiled from SCSS via **node-sass**. On `Missing binding` errors: `npm rebuild node-sass` (see `.claude/rules/build/env.md`).
- This theme is what every Svelte/UID page rebrands against — don't hardcode equivalents in pages (see `.claude/rules/frontend/bonita-theme-first.md`).
